Embed the Gad WASM in your site

The Gad WebAssembly module runs the compiler, VM, formatter, doc extractor and debugger entirely in the browser — no server. It installs a small set of functions on the JS global object, each taking strings and returning a JSON string.

1. Get the files

Download gad.wasm and wasm_exec.js from the Download page (both are attached to every release). wasm_exec.js is Go's WASM loader and must match the Go toolchain the module was built with — always ship the one from the same release.

2. Load it

<script src="wasm_exec.js"></script>
<script>
  const go = new Go();
  WebAssembly.instantiateStreaming(fetch("gad.wasm"), go.importObject)
    .then(r => { go.run(r.instance); onReady(); });

  function onReady() {
    // window.gadRun / gadFormat / gadDiagnose / gadDoc / … are ready.
    const r = JSON.parse(gadRun('println("hi"); return 6 * 7'));
    console.log(r.stdout, r.result); // "hi\n" "42"
  }
</script>
A long-running script blocks the thread. For a responsive UI, load the module inside a Web Worker — exactly what the Playground does.

3. The API

Each function returns a JSON string. sourceType selects the dialect: ""/"gad" (plain Gad), "gadTemplate" (mixed .gadt) or "gadx".

FunctionReturns (JSON)
gadRun(src[, sourceType[, argsJSON]]){ ok, stdout, stderr, result, diagnostics }
gadFormat(src[, sourceType]){ ok, source, diagnostics }
gadDiagnose(src[, sourceType]){ diagnostics: [{line, column, message, severity}] }
gadDoc(src, sourceType){ markdown } | { error }
gadDocData(src, sourceType){ doc } | { error }
gadEval(src, expr, repr){ ok, value, error, stdout }
gadTranspile(src, mixed){ ok, source, diagnostics }
gadInspect(session, expr, src){ ok, inspect } | { ok:false, error }
gadDebugStart / gadDebugCommand / gadDebugEval / gadDebugStopdebugger stepping protocol

Prefer a ready-made editor?

The @gad-lang/ide-vuetify and @gad-lang/ide-react packages wrap this module into a full IDE component (editor, run profiles, debugger, inspector), and @gad-lang/codemirror-gad / @gad-lang/prism-gad provide syntax highlighting.
