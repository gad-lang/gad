#### Overloaded time Operators

- `time + int` -> time
- `time - int` -> time
- `time - time` -> duration
- `time < time` -> bool
- `time > time` -> bool
- `time <= time` -> bool
- `time >= time` -> bool

Note that, `int` values as duration must be the right hand side operand.
